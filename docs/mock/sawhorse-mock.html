What this mock decides

In the week-3 alpha
  • Left rail: the tools people's hands already know, same keys, our own glyphs.
  • Inference dots in our own four colors, named in the legend.
  • Value bar at the bottom: type mid-gesture, fractional inches first-class.
  • Right panel: Outliner, Tags, Cut list, Render. Cut list ships day one.
  • Render panel: presets, one credit per render, packs with no account.
